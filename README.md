# ConnectWBT Platform

**Brand:** ConnectWBT  
**Department:** Identity And Project Services  
**Status:** `source-reviewed-deployment-recorded`

## Overview

A shared backend for identity, projects, membership, collections, token wallets, AI authorization, and payment workflows across connected products.

## Who It Is For

Application teams that need shared account, project, and platform services.

## Capabilities

- Register users and validate identity
- Create and manage projects and project memberships
- Expose project collections and document APIs
- Manage token packages, wallets, ledgers, and purchases
- Provide shared integration endpoints for applications

## How To Use It

1. Register or authenticate through a client application
2. Use the documented API or SDK with an authorized token
3. Associate operations with the correct project
4. Keep provider secrets on the server side
